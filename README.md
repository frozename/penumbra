# penumbra

Local-first memory, compression, and learned-routing layer for hybrid-AI workflows. Sibling to Nova, Sirius-Gateway, EmberSynth, and LlamaCtl.

See `docs/superpowers/specs/` for the V1 design. See `docs/superpowers/plans/` for implementation plans.

## Packages

- `@penumbra/agentchat`: Cross-agent group-chat orchestrator.
- `@penumbra/cli`: Command line interface.
- `@penumbra/core`: Core memory and routing layer.
- `@penumbra/daemon`: Background API daemon.
- `@penumbra/e2e`: Smoke tests and end-to-end testing.
- `@penumbra/mcp`: MCP integration for the core system.
