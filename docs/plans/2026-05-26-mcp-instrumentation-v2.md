# MCP Instrumentation Plan

> **For Gemini:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement per-invocation logging for MCP tools (calls, arg/result bytes, errors, origin) to JSONL.

**Architecture:** We add a wrapper around all MCP handlers that records `JSON.stringify` byte counts of args and results. The wrapper logs a single JSON line to ~/.local/state/penumbra/mcp-invocations.jsonl. We apply this wrapper in `server.ts` for internal tools and `federation/client.ts` for federated tools. We add an analysis script to read the logs. The entire feature is opt-in via `PENUMBRA_MCP_INVOCATION_LOG=1`.

**Tech Stack:** TypeScript, Bun, Zod (config).
