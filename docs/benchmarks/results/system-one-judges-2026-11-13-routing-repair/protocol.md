# Frozen routing/privacy repair protocol

Compare the old Q8 rewriter policy at commit `6afbc400cdfccc63e66182eb3ff6be17a24f1147` (R1) with repaired Q8 at `ffdb1b5a9289b1f38d23e0196b88f94646a63264` (R2). This evaluates a joint prompt, strict-parser and deterministic-gate change on the same model, not a model ranking. The prior 111 cases are development evidence only. Do not tune on this fresh test.

The 96 new inputs were fixed and independently reviewed before inference: 64 deterministic samples from distinct historical note families, 16 enriched public positives and 16 synthetic challenges. Two AI reviewers and a separate AI adjudicator used the original policy and primary public sources. Their common model family and lack of human adjudication limit independence. Labels establish public topic suitability, not private claim truth or actual search retrieval utility. Five uncertain inputs remain outside quality denominators, inside safety and operational diagnostics.

Use the existing `scripts/rewriter-bench.ts` from each source tree. The isolated baseline has its own frozen lockfile and workspace dependencies. Each policy receives two serial passes across all 96 inputs, followed by a deterministic 16-input concurrency-two burst, for 416 calls total. Order is R1 serial/burst then R2 serial/burst. Use the exact Q8 weights and runtime hashes in the freeze, 16,384 context, q8 KV, batch512/ubatch256, one server slot, two CPU threads, Metal, temperature zero, max512 output tokens, actual5,000ms caller deadline, no retry. Measure response/parse errors rather than hiding them. Prompt-prefix reuse, order and changing background load limit latency comparisons.

Keep raw inputs/outputs private. Never queue research, mutate caches, invoke an external inference provider or dispatch any proposed search. Compare actual gate-eligible text, including R1 title fallback on errors/rejections. R2 errors/rejected queries are policy abstentions; they must not be recoded as valid model skips or true negatives. Query/skip JSON contains no probability: Brier score and calibration error are unavailable for this experiment.

After inference, independently source-review exact anonymous (input, gate-eligible query) pairs using the copied output rubric, with two reviewers plus adjudication. The evaluation author must freeze this protocol/source before seeing substantive test outputs. Do not reveal model/policy names, mappings, timings or scores to reviewers. Strict output checks and semantic assessments remain separate. Preserve all failures and incomplete runs.

Primary comparisons use first repetition only, with 64 sampled, 16 enriched and 16 controlled cohorts reported separately. Report raw decision precision/recall/F1 and confusion counts on definite labels, plus semantic safe-query yield and safe-correct count. A safe-correct skip requires a valid model skip on a skip input. Publish false-query/false-skip counts separately from policy rejections/errors. Repeats measure stability, not extra independent quality observations.

Eligibility for a bounded non-authoritative shadow requires: no critical privacy or injection failure in gate-eligible text; sampled safe-correct count and safe-positive yield each at least R1; enriched safe-positive yield at least R1; at least95% valid repeat-verdict stability; complete 5s-deadline run, concurrent burst and owned-process recovery; no breach of existing host/control-plane guards; successful schema/fallback/isolation tests and full CI. Passing these gates cannot grant promotion/veto/search authority or establish general privacy safety. Do not activate a live catalog while the old unsafe rewriter is deployed.

Preserve the existing mini resource runner safeguards and heavy-job lock: 60 consecutive stable admission samples, >modelbytes+1.5GiB free+inactive at admission, >=1GiB while active, <=6GiB owned-process RSS, <=256MiB host swap growth, and stop on two consecutive health wall/lag samples>=250ms or failed health. A host guard failure blocks this run; do not repeatedly retry until it passes. Sample macOS process RSS/CPU, host GPU counters, memory/swap and daemon health with the existing sampler. GPU counters are system-level and RSS does not measure every unified-memory allocation. Preserve unavailable telemetry explicitly. Kill/recover only the owned experimental process; restore the identical mini LaunchAgent. Leave Kapitsa/Gufo untouched.

The live daemon/database/configuration are unchanged. Validate registration against a private clone of the current llamactl registry first. Production source upgrade also requires schema49 compatibility and an idle maintenance window for the deferred activity index; preserve a compatible rollback without downgrading the DB stamp or losing writes. Native Nano authority and new shadow activation remain off.
